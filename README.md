# 성공적인 직업생활 마스터

특성화고 교과 **「성공적인 직업생활」(2015 개정)** 전 단원 학습도구.
배우기(수업자료) → 테스트(개념게임) → 과제 제출을 한 파일에 담은 단일 HTML.

- **6단원 18주제 · 117문항** — Ⅰ일과 직업생활 · Ⅱ기업과 산업 활동 · Ⅲ직업능력·평생학습 · Ⅳ취업과 창업 · Ⅴ근로관계·산업안전 · Ⅵ직업윤리와 직업 사회
- 📖 **배우기** : 정답을 다 보여주는 개념 카드/표 (수업자료·자습)
- 🎯 **테스트** : 4지선다 게임(보기 셔플·연출·콤보·별점·해설)
- 📤 **과제 제출** : `?rc=선생님_시트주소` 링크로 열면 결과가 구글시트로 모임


## 📽️ 전자칠판 수업자료 (class.html)

교사가 앞에서 끌고 가는 **수업용 화면**입니다. → https://hongyul67-cpu.github.io/job-life-master/class.html

- **6단원 22장 슬라이드 · 그림 18종 · 빈칸 89개**
- 그림은 전부 **직접 그린 SVG** — 전자칠판 대형 화면에서 선명하고, 확대해도 안 깨집니다
- **빈칸 같이 풀기**: [빈칸 열기]를 누르면 하나씩 공개. 학생에게 먼저 물어보고 → 답이 나오면 공개
- **판서**: 화면 위에 바로 필기(4색) · 지우기
- **프레젠터 리모컨**: Space/→/PageDown 다음, ← 이전, A 모두 열기, P 펜, Esc 목록

## 사용
- 학생/수업: `index.html`을 열면 배우기·테스트 사용(제출 버튼 없음)
- 과제 걷기: [결과수집 링크 생성기](https://hongyul67-cpu.github.io/links/link-builder.html)에서 `?rc=` 링크 발급 후 배포
