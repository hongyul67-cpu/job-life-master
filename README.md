# 성공적인 직업생활 마스터

특성화고 교과 **「성공적인 직업생활」(2015 개정)** 전 단원 학습도구.
배우기(수업자료) → 테스트(개념게임) → 과제 제출을 한 파일에 담은 단일 HTML.

- **6단원 18주제 · 117문항** — Ⅰ일과 직업생활 · Ⅱ기업과 산업 활동 · Ⅲ직업능력·평생학습 · Ⅳ취업과 창업 · Ⅴ근로관계·산업안전 · Ⅵ직업윤리와 직업 사회
- 📖 **배우기** : 정답을 다 보여주는 개념 카드/표 (수업자료·자습)
- 🎯 **테스트** : 4지선다 게임(보기 셔플·연출·콤보·별점·해설)
- 📤 **과제 제출** : `?rc=선생님_시트주소` 링크로 열면 결과가 구글시트로 모임


## 📽️ 전자칠판 수업자료 (index 안에 있습니다)

교사가 앞에서 끌고 가는 **수업용 화면**입니다.
예전에는 `class.html` 이 따로 있었지만, 겉으로 보이는 입구를 하나로 모으면서
**`index.html` 홈의 「📽️ 수업자료 열기」** 안으로 들어왔습니다.

- **6단원 30장 슬라이드 · 그림 18종 · 빈칸 100개**
- 그림은 전부 **직접 그린 SVG** — 전자칠판 대형 화면에서 선명하고, 확대해도 안 깨집니다
- **빈칸 같이 풀기**: 요점의 빈칸을 누르면 답이 드러납니다. 학생에게 먼저 물어보고 → 답이 나오면 누르세요
- **넘기기**: `←` `→` 키(프레젠터 리모컨) 또는 화면 아래 [◀ 이전] [다음 ▶]
- 화면은 모든 도구가 함께 쓰는 `board.js`, 원고는 `lesson.js` 가 맡습니다
- 슬라이드는 교실 화면(1920×1080)에서 **30장 전부 스크롤 없이** 한 화면에 담기도록 맞췄습니다

> 판서(펜)와 글씨 크기 조절은 공용 화면으로 통일하면서 빠졌습니다(2026-08-26 사용자 결정).


## 🏅 랭크(계급) 시스템

학생 몰입을 위한 경쟁 요소. **아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아 → 마스터** 8단계.

- **RP 획득**: 정답×10 + 별(3★ 50 / 2★ 25 / 1★ 10) + 만점 보너스 50
- **주제별 최고 기록만 합산** — 같은 문제를 반복해도 점수가 부풀지 않음(파밍 방지)
- 홈 상단에 티어 엠블럼·누적 RP·다음 티어까지 남은 점수 표시
- 승급 시 전체화면 승급 배너
- 전 주제 만점 = 2,720 RP · 마스터 도달 = 2,450 RP(약 90%)
- 공용 PC용 **랭크 기록 초기화** 링크 제공
